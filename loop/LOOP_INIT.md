# Chirality Library development entry

The Chirality Library (`sgttomas/chirality-library`) maintains the shared roles,
workflows, tools, references and publications used by the Chirality projects.
The [accepted PRD](../docs/PRD.md) defines its commitments; the
[accepted decomposition](../execution/_Decomposition/_LATEST_ACCEPTED.md)
locates the allocated work. Read [AGENTS.md](../AGENTS.md) for standing
instructions, authority and the distinction between Library and private Root.

The Library has published editions and continues maintenance under new steering.
Continue from actual Work, Git and PR state rather than treating earlier gate
decisions, accepted allocation or prepared paths as a current backlog or
fulfilled result.

## Locate the selected work

From the brief's purpose or affected holding, find the relevant ScopeOfWork under
`execution/PKG-nn/DEL-nn-nn/`. Read its `Work/` and `deliverable.yaml`, then the
PRD clauses and sources needed for this slice, without a global state census. Code pointers indicate relevance,
not exclusive ownership. For changes to this entry, begin with the
[discovery scope](../execution/PKG-01/DEL-01-01/ScopeOfWork.md) and
[its Work](../execution/PKG-01/DEL-01-01/Work/DiscoveryBasis.md).

From the repository root, for example:

```sh
python3 -m tools.deliverables --project . neighborhood DEL-01-01
```

Use the actual selected DEL. `impact <DEL>` discovers downstream reach;
`touches <rev|PR:n>` finds change relevance; `check` examines declarations;
`dag-diff <revision>` compares needs against an identified basis. The
[query guide](../tools/deliverables/README.md) states Git/HEAD, Python/PyYAML
prerequisites and limits. A failed query is not an empty result: report the
failure and inspect relevant declarations and sources directly. Queries do not
decide input suitability, completion or acceptance. Examine actual input
conditions and evidence; usable inputs need not await an entire neighboring
Deliverable's completion. Keep unknowns visible while unaffected work continues.

Select methods through the [workflow guide](../workflows/README.md) and its
consumed index, retaining source-qualified identity and loading only needed
resources. Use [coordinated knowledge work](../workflows/coordinated-knowledge-work/WORKFLOW.md)
for related contributions. Agent 0 retains purpose and continuity; implementation
owners carry their contributions through ordinary repairs and integration.
If opted in, send activity summaries and consultations to the existing
INTERLOCUTOR session under AGENTS.md.

## Maintain holdings and receive contributions

A consumer request or contributed candidate enters through Library Agent 0.
Establish its purpose, exact source basis, owning locality, affected uses,
bounded writes, decision and review rights, checks and supported return route.
Obtain the required Library content approval before integration. Route action
in another repository through that project's Agent 0. The contributing project
owns its adoption and product work.

Before changing a holding, inspect the uses and required resources the change
affects. For relocation or retirement, establish authority, replacement or
historical standing, and recoverable source as AGENTS.md requires. Follow
`create-workflow` before creating or revising a reusable method. Regenerate and
check consumed indexes when their owning sources change; do not hand-edit
derived catalogs or invent an index change when generated bytes stay the same.

Carry the result and proportionate verification into affected ScopeOfWork,
Work and need declarations in the same PR. Leave unchanged declarations alone.
The [reconciliation method](../workflows/bounded-reconciliation/WORKFLOW.md)
compares results under commitments; [reflect-on-work](../workflows/reflect-on-work/WORKFLOW.md)
examines whether that basis or practice still serves the purpose. When a finding
calls purpose, commitments, explanatory framing or the chosen practice into
question, use reflection with the human and Agent 0.

## Content review

The owner wants to understand proposed library content changes in broad strokes
and review and approve them before integration. Present the affected material,
what would change, why and the consequences, with the actual edits available.
This applies to meaning and behavior, organization and selection, and mechanical
maintenance; no document type or improvement class is exempt unless the owner
says so. Investigation, drafting and verification may proceed within the
authorized undertaking. Apply decisions already given; obtain approval for
changes outside the approved proposal before integration. Proposed replacement
instructions are examined under their preceding basis. Obtain their adoption
approval under that basis before applying them.

## Examine, publish and coordinate adoption

Use the affected scope's criteria and AGENTS.md's proportionate verification
rule. Reuse evidence that supports the actual claim and identify what remains
unverified. `tools/run_affected_tests.py` selects tool checks; CI supplies the
required hosted result. The workflow guide covers metadata and index checks.

Integration on `main`, publication of an edition and a consumer's adoption are
separate decisions. The [consumer route](../README.md#obtain-and-use-the-library)
explains obtaining, source selection, update inspection and release notifications;
[DEL-05-01](../execution/PKG-05/DEL-05-01/ScopeOfWork.md) and its Work own
publication preparation and evidence. A consumer records its selected revision;
merging a change here does not update that selection. Coordinate affected
interfaces and adoption with the current project Agent 0 under AGENTS.md.
Acceptance and release remain owner acts; no publication follows automatically
from this operating cycle.

App v4 and SWBPIPE own their repositories; Root owns its separate measurement,
improvement and service work. The Library's instructions and Git grant transfer
no authority to them. App v3 and Runtime remain frozen. Pre-library execution
is recoverable from private Root history at or before `05d96f3e11`, not a standing
backlog. Keep private information outside this public Library.
